# 绿宝记账 隐私政策（草稿，上线前请运营者逐句确认）

更新日期：2026 年 11 月

欢迎使用「绿宝记账」。我们只做一件事：帮你记账，并帮一群人把共同花的钱算清楚。下面用大白话说明我们会用到你的哪些信息。

## 一、我们会收集和使用哪些信息

1. 你的昵称：由你自己在小程序里填写（也可以用微信给的昵称建议）。用途：在共同账本里显示「谁付了钱、谁该出钱」。你可以随时改成别的名字。
2. 你记录的账目内容：金额、分类、日期、备注。用途：为你汇总统计；在共同账本里为所有成员算账。备注请不要写身份证号、银行卡号、密码等敏感内容。
3. 共同账本里的信息：账本名字、成员名字、每笔账的付款人和分摊情况、转账确认记录。用途：让同一个账本的成员看到同样的账。
4. 微信 OPENID：这是微信给你在本小程序里生成的一个编号，不是你的手机号，也不是微信号。我们的云函数会自动取得它，用来判断「你是不是这个账本的成员」。不用你额外授权或填写。
5. 本机存储：你的个人账目默认只保存在你手机的本地存储里。

## 二、我们不收集什么

- 不收集手机号、真实姓名、身份证、银行卡信息。
- 不收集微信头像、位置信息、通讯录、相册、相机、麦克风内容（当前版本没有这些功能）。
- 不读取你的微信聊天记录、微信支付账单；不读取群成员。
- 不使用第三方广告或第三方统计工具。
- 不提供支付、收款或代转账服务。转账请你们自己用微信完成，本小程序只记录「谁说已经转了、谁确认收到了」。

## 三、信息保存在哪里、保存多久

- 个人账目：默认只保存在你手机本地。只有你主动点「我的 → 备份到云端」，才会上传一份到微信云开发（服务器在中国大陆），云上只保留最近一次备份。
- 共同账本：保存在微信云开发的云数据库（服务器在中国大陆）。
- 保存期限：直到你删除为止。账本创建者删除账本后，该账本的全部数据会从云端删除。

## 四、谁能看到你的信息

- 同一个共同账本的成员，能看到账本里的成员昵称、账目、分摊和转账确认记录。
- 分享给朋友的邀请卡片里，只有账本名字，不含任何金额和账目。朋友点开后需要自己确认才会加入。
- 我们不会出售你的信息，也不会向无关的第三方提供。

## 五、你的权利和如何操作

- 修改或删除某一笔账：在对应页面操作。
- 退出共同账本：在账本页点「退出账本」（需要先对清账）；你已经记进去的账目会保留在账本中，用于其他成员继续对账。
- 创建者删除整个账本：在账本页点「删除账本」。
- 删除全部数据：「我的 → 清除我的全部数据」，会清空本机账目，并删除云端备份、匿名化你在共同账本里的身份。
- 导出：「我的 → 导出为表格」。
- 有任何问题可以联系我们：（上线前请填写你的联系邮箱）

## 六、未成年人

未满 18 周岁的用户，请在监护人同意下使用。

## 七、政策更新

如果我们增加新的功能（例如拍照识别），会先更新本政策并重新征得你的同意，再开始使用相关信息。
